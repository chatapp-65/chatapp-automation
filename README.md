# Chat App Automation with Selenium

This project automates a chat application hosted at:
https://app65656565.pythonanywhere.com/chat

## Features
- Sends a message in the chat input
- Submits it using Enter key
- Verifies the message appears in the chat area

## Setup

1. Install dependencies:
   pip install -r requirements.txt

2. Make sure ChromeDriver is installed and available in PATH.

3. Run the script:
   python chat_app_test.py

## Notes
Replace dummy element IDs like `chat-input-box` and `chat-container` with your actual HTML element IDs or class names.
